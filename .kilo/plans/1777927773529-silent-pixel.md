# Portfolio Website - Muhammad Bevan Alqarana

## Overview

Membuat portfolio website dengan style **Neobrutalism** menggunakan **Next.js + Tailwind CSS** untuk keperluan hunting internship di bidang Business Analyst, Data Analyst, dan IT Support.

**Inspirasi:** https://m-fikri-portfolio.vercel.app/ (struktur & feel-nya, bukan copy-paste)

**Target audience:** Recruiter / HR untuk posisi intern BA, DA, IT Support

## Design System - Neobrutalism

### Color Palette (Combined/Multi-accent)

```
Background:     #FFFDF7 (warm white)
Surface:        #FFFFFF
Text Primary:   #1A1A1A
Text Secondary: #4A4A4A
Border:         #000000

Accent Blue:    #3B82F6
Accent Yellow:  #FACC15
Accent Pink:    #EC4899
Accent Green:   #22C55E
Accent Purple:  #8B5CF6

Shadow:         #000000
```

### Neobrutalism Tokens

```css
Border:         3px solid #000
Border Radius:  8px (sedikit rounded, bukan 0 total)
Box Shadow:     6px 6px 0px #000
Hover Shadow:   8px 8px 0px #000
Active Shadow:  2px 2px 0px #000 (pressed effect)
```

### Typography

- Heading: Space Grotesk, 700-800 weight
- Body: Inter, 400-500 weight
- Monospace accent: JetBrains Mono (untuk code/tech elements)

## Implementation Steps

### Phase 1: Project Setup
1. Initialize Next.js 14 project with TypeScript + Tailwind CSS
2. Install dependencies: framer-motion, lucide-react, next-intl
3. Configure Tailwind with neobrutalism design tokens (colors, shadows, borders)
4. Setup Google Fonts (Inter, Space Grotesk)
5. Setup i18n with next-intl (locale routing, translation files)
6. Create base layout with globals.css

### Phase 2: Design System & UI Components
7. Create neobrutalism utility classes (custom CSS)
8. Build reusable UI components:
   - Button (variants: primary, secondary, outline)
   - Card (neo-brutal style)
   - Badge/Tag
   - SectionTitle
   - LanguageToggle
9. Setup Framer Motion animation variants

### Phase 3: Layout Components
10. Build Navbar (responsive, mobile menu, language toggle)
11. Build Footer

### Phase 4: Section Components
12. Hero Section (with animations)
13. About Section
14. Career Focus Section (3 role cards)
15. Projects Section (with filter tabs)
16. Skills Section (grouped categories)
17. Education Section (timeline)
18. Certificates Section (grid with placeholders)
19. GitHub Section
20. Contact Section (with form)

### Phase 5: Content & i18n
21. Write all content in Indonesian (messages/id.json)
22. Translate all content to English (messages/en.json)
23. Wire up translations to all components

### Phase 6: Polish & Optimization
24. Add scroll animations (intersection observer + framer motion)
25. Add smooth scrolling navigation
26. Responsive design check (mobile, tablet, desktop)
27. SEO meta tags & Open Graph
28. Performance optimization (image optimization, lazy loading)
29. Accessibility check (aria labels, keyboard navigation, contrast)

### Phase 7: Deployment
30. Setup Vercel project
31. Connect GitHub repository
32. Deploy & test

## Notes & Considerations

- **Placeholder content:** Semua section akan dibuat dengan placeholder yang mudah diganti. User tinggal update data di `src/lib/data.ts` atau translation files.
- **Foto profil:** Akan menggunakan placeholder avatar. User bisa ganti nanti.
- **CV:** Section download CV akan ada tapi file PDF-nya placeholder.
- **Responsive:** Mobile-first approach, semua section harus terlihat bagus di HP.
- **Performance:** Gunakan Next.js Image component untuk optimasi gambar.
- **Dark mode:** Tidak termasuk dalam scope awal (bisa ditambah nanti jika diminta).
- **Contact form:** Akan menggunakan mailto link atau Formspree untuk fungsionalitas tanpa backend.
